Session Protocol · run in order, every session

Date & time verification — MANDATORY

Confirm today's date/time and double/triple-check it against the live slate before any game-state claim. Never reference plays, dates, or P&L from a vague sense — only from a confirmed source. Zero tolerance for attribution errors.

Pre-filter gate — hard gate

Pull all 30: streaks, run diffs, splits. PLAY = +RD & W1+. FADE = −RD & L1+. Cross-ref slate; perfect collisions = top priority. Fail the gate = dead on arrival — no price, pitching edge, narrative, or Dog Days lean overrides it.

Full trigger grid — walked in order, visible

Grade every survivor against the whole checklist as a marked grid (fires / no-fire / direction) before totaling. Never just the top-of-mind triggers.

Score → size → price LAST

Cumulative score decides play / pass / size. Pricing & structure (straight / parlay / RR) come last, scraped live, best number locked.

Root cause of every past failure: grading from memory instead of running the steps in order. Date → gate → grid → price. No skipping to the interesting part.

Weighted Overlays · +0.5 stacks

T-REGHome/road regression

Means ~.530 home / ~.470 road, 15-game min. Premium (~+140 band): home >.620 fade fav / <.440 back dog; road >.560 fade / <.380 back. Strong: home >.680 or <.380. Direction check mandatory — extreme-LOW home split is a BUY, not a penalty. Discount when a bad team's split is simply deserved. Source: CBS Sports splits.

T-INJInjury

Weighted, not a last check. MVP bat out = meaningful fade; ace scratch = biggest lever; closer IL boosts T8. Hits hardest first 24–48hr (market lag).

T-CFFraming +ABS

+0.5 only. Elite Savant +12 & poor −5 & gap ≥10 fires. Pull Savant every 2 weeks.

T-FATFatigue ladder

Resets only on a scheduled day off. Home: G6 watch · G7+ +0.5. Road: G6 +0.5 · G7 +1.0 · G8 +1.5 · G9+ +2.0 max. Bullpen-game opponent = variance flag, not weakness — never a green light to lay juice.

Situational & Reversion

Run Line · Parlay · Exotic

RLRun line universal

Plus-money dog always +1.5, never −1.5. Fav −1.5 add-on v2.5: ML clears gates + −1.5 pays +140+ + RD gap clears the calendar (Apr +10 · May +15 · Jun +20 · Jul +25 · Aug–Sep +30) → auto-play both at 50% of ML risk. G9+ fade zone = skip RL.

P/RRStreak parlay

Play list: W2+ · +RD · strong SP · priced fav. Fade list: L2+ · −RD only. 2-team ≤$200, 3 plays = RR $200. Exotic bucket only, never straight, never mixed with T1/T11.

HOTFav parlay priority

Route dominant hot teams to legs only, never straight. Strongest vs weak/cold opp with a good arm.

Coors Over at total ≤10.5 (STRONG ≤9.5 or amplifiers; pass ≥12). Pitcher-Park Under at Oracle/T-Mobile/Petco/Tropicana/Busch when total ≥8.5, STRONG night + elite SP. RL parlay 2-team max $50–100.
